# Export-only PPTX resize hints

`source.export(document, { resize })` accepts a `Map<objectId, { height }>` or a record of the same values. Height is a positive integer in EMU. This low-level option consumes a host measurement; it does not measure fonts or change the editor document, revision or undo history. The renderer and PresentationEditor supply measurements at export time after one bounded font wait for both shrink and resize. Loads settle independently; each kind checks only its own required fonts. A rejected load skips only a kind whose fonts remain unavailable, and a timeout skips only a kind whose fonts are still unavailable at the deadline. Available fonts can be measured even while unrelated fonts are loading.

Hints apply only to top-level, writable, unrotated rectangular PPTX text boxes whose snapshot body layout is `autofit: 'resize'`. They grow the existing height; smaller heights, unsupported targets and malformed hints throw `Invalid resize measurement`. A nonempty hint for an untouched native object also throws `Invalid resize measurement`: measured hints apply only to authored objects and native objects whose canonical `text`, `geometry`, or `bodyLayout` changed since import. Empty maps remain byte-identical no-ops. Native eligibility is checked against the privately retained source, not caller-provided flags. Signed sources still reject edits before hint validation. ODP, groups, flips, vertical text, nonrectangular/custom/adjusted geometry, unresolved native metric layouts and `wrap: 'none'` are unsupported.

The exported width and x remain fixed. Top anchors preserve y; middle anchors preserve the center (rounded to integer EMU); bottom anchors preserve the bottom. **The new y may be negative: the box may extend above the slide or overlap nearby objects.** No neighboring objects move. The canonical document and canvas retain the drawn size. PowerPoint may subsequently grow or shrink the frame when its text is edited; the exported `a:spAutoFit` remains in place.

Measure the same immutable document snapshot that is passed to export. The exporter captures document and hint values before its first await and merges effective growth through its ordinary geometry writer. Other geometry fields and text formatting are retained. With no effective edits, export stays byte-identical; untouched ZIP parts stay byte-identical on edits, while untouched XML within rewritten parts is preserved semantically.

The existing `fit` shrink option uses the same authored/changed-native policy. A stale shrink hint for an untouched native object throws `Invalid autofit measurement`; it is not silently ignored. Resize and shrink can accompany one another for different eligible objects. No font-size or shrink-scale change is introduced by `resize`.

Theme `a:objectDefaults` are not resolved into canonical layout. If the applicable `txDef` (text box) or `spDef` (shape) has nonempty `bodyPr` or `lstStyle`, native text metrics are conservatively unsupported, even when some local properties override them. This protects both resize eligibility and shrink measurement; empty defaults and defaults for the other object kind do not disable measurement. The theme XML remains untouched.

The reader records this eligibility summary as read-only `theme.extensions.pptxObjectDefaults` flags (`txDef` / `spDef`, true means unsupported inherited defaults). New authored resize targets are checked against the retained theme as well; new slides use the first retained layout, matching the source writer. Caller edits to these appearance flags cannot grant resize eligibility.

## Measurement and export outcomes

`measureResizeFits(document, { fonts, canvas?, baseline? })` lays out the same canonical text model as shrink, at authored width with explicit font sizes and no automatic font scaling. It grows to natural text height divided by `RESIZE_FIT_POLICY.heightMargin` (0.97), plus insets, rounded upward to EMU. The existing shrink margin is unchanged. Already-fitting boxes keep their height. Resize and source share structural eligibility, the authored/changed-native predicate, and geometry arithmetic; native metadata and applicable theme object defaults must be supported. Unsupported fonts/text metrics, groups, rotation, flips, wrap:none and ODP produce skips. Untouched native boxes are skipped with reason `unchanged-native`, so browser font substitution cannot grow a frame PowerPoint already sized. If `baseline` is omitted, native boxes are conservatively treated as unchanged.

`waitForAutofitFonts(document, { fonts, timeoutMs?, kinds?, baseline? })` waits once (default2000ms) on the union of eligible font queries. `waitForShrinkFonts` remains available for shrink-only callers. The editor captures one snapshot before this wait, measures and exports that exact snapshot against `source.document`, rechecks permissions and suppresses stale work after source/editor replacement or unmount.

`onExport(result, { revision, shrinkFit, resizeFit })` adds resize status without changing shrinkFit. `resizeFit.count` is the number of emitted growth entries; `stats` partitions candidates into measured/skipped/failed, and `reasons` counts fixed content-free diagnostics, including `unchanged-native`. Measured includes already-fits (count0); no-resize and empty text are normal skips. Partial success retains valid hints while disclosing skipped/failed boxes. Exceptions and timeout remain observable while export proceeds without the unavailable hints. The host shows each kind separately and summarizes untouched native boxes as “N text boxes unchanged since import were left as PowerPoint saved them”; it never claims that skipped boxes were fitted.

The canvas and undo history remain unchanged. Browser font substitution can differ from Office fonts even after FontFaceSet reports readiness; measurements are approximate, not PowerPoint layout parity. A later native edit may grow or contract further. No collision avoidance or off-slide clamping is performed. Protected/server hosts can omit hints or provide their own authorized measurements; this feature does not transfer protected content into the browser.
